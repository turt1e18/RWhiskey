# R-Whiskey

**오늘의 기분과 취향에 어울리는 한 잔을 찾아보세요.**

R-Whiskey는 상황에 맞는 위스키와 칵테일을 추천하고, 그 경험을 기록할 수 있는 서비스입니다.

## 홈페이지에서 소개하는 경험

| 기능 | 내용 |
| --- | --- |
| 맞춤 위스키 추천 | 날씨, 기분, 선호하는 맛 등 오늘의 상황을 선택해 위스키를 추천받습니다. |
| 칵테일 추천 | 취향과 분위기에 맞는 칵테일, 재료와 제조법을 확인합니다. |
| 추천 결과 카드 | 추천한 술의 특징, 추천 이유와 음식 페어링을 한눈에 살펴봅니다. |
| 나의 노트 | 로그인 후 자신의 시음 기록을 확인하고 관리합니다. |

홈페이지의 추천 흐름은 **상황과 기분 선택 → 맞춤 추천 → 결과 확인**으로 이어집니다. 랜덤 위스키 추천은 화면에 소개되어 있으나 현재 준비 중입니다.
